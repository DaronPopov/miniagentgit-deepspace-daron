# PASS 12A → PASS 12B handoff

1. **Block exposure until ingress and cost can be enforced.** Establish a
   supported trusted-account perimeter for the assigned origin, including
   direct canonical host access, or enforce app-wide admission and usage.
   Verify production credit exhaustion behavior and Worker, SQLite and
   request entitlements with the provider. Keep estimates distinct from caps.
2. **Bound the parser.** Qualify a hard CPU and memory boundary for the
   synchronous call and establish state recovery when the platform interrupts
   work. Existing local input and AST budgets are still useful limits.
3. **Establish non-destructive recovery.** Confirm production backup, restore
   and disable-routing behavior for RepositoryRoom and JobRoom. Verify class
   manifests before rollback. Test hosted restart durability after approval.
4. **Qualify users and agents.** After safe exposure, arrange a fresh provider
   login in an isolated browser, a separate approved identity for tenant
   tests and a real coding agent with a production origin-scoped credential.
   Exercise expiry/renewal, verify user and agent route separation and
   document revocation latency for previously issued credentials.
5. **Retest the full hosted workflow.** Observe known-ID repository lookup,
   HEAD, parent commit, immutable files, CI jobs and both receipts in the
   dashboard. Reconnect, re-read and qualify replay and stale-HEAD behavior.
   Treat client transport compatibility as an explicit gate.
6. **Track dependency advisories.** Reassess picomatch and esbuild against
   supported patches and inspected production reachability.
